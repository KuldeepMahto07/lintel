What it does

From a question to a finished change.

reads

Grounded in your model

It works from the open drawing: rooms, doors, stairs and walls, with their real sizes.

drafts

Does the edit for you

Ask for a change and it prepares the exact properties to update, ready for review.

It can propose. It can't apply. Every edit waits for a person to approve it.

Questions

Asked by architects.

Does it ever change the model on its own?

No. The assistant has no tool that applies changes. It can only draft them. A change reaches your model only after a person clicks Approve, and the plugin refuses it if the model changed in the meantime.

Which software does it run in?

Rhino 8 first. SketchUp, Revit and Archicad come next, in the order pilot firms ask for them. The rules, history and dashboard stay the same across all of them.

How does it know what a door is in Rhino?

Rhino has no door objects, so Lintel uses a light convention: layers such as Lintel::Doors plus a few text attributes (width, exit). A sample model shows the setup in a minute.

Can I undo something I approved?

Yes. Ctrl+Z in your CAD app undoes the whole change, and the dashboard can revert it too. Both are logged.

Does it quote the building code?

No. Lintel cites the section number your rule refers to and asks you to confirm it against your jurisdiction's adopted edition. It never reproduces code text.
