# Pricing strategy

**Status:** 🟡 In progress

Part of [11 · Conversion](../README.md) in the [Lintel SaaS plan](../../README.md).

Draft, to test in interviews. Heron's published (concept) prices were $99 and $295/mo.

| Plan | Price | For |
|---|---|---|
| Free | $0 | 1 project, checks + chat, no edits |
| Pro | $39/seat/mo ($390/yr) | Approval-gated edits, unlimited projects, firm rules, 1 host |
| Firm | $99/seat/mo, min 3 seats | All hosts, shared approval queue, team audit log, rule import, priority support |
| Enterprise | custom | SSO, on-prem/local backend, DPA, custom rule packs |

Claude usage is included up to a fair-use cap; top-up credits above it. 👤 Validate price points in interviews ($29/$49/$79 test).
